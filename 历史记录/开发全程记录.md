## 一、项目简介

**ZTC** 是一款**纯客户端**的租赁合同审查安卓应用：用户粘贴合同文本，AI 自动识别类型（住宅/商铺/办公/设备/车辆）并出具风险报告。

- **纯客户端**：审查逻辑全部内嵌在 APK，不依赖服务器
- **用户自带 API Key**：每个用户填自己的 key（支持 DeepSeek / Kimi / 通义 / 智谱 / Ollama / 自定义）
- **隐私**：合同文本和 key 只存手机本地（localStorage），不上传任何服务器

## 三、技术决策记录（重要！）

| 决策 | 选择 | 原因 |
|---|---|---|
| API 格式 | OpenAI 兼容（openai SDK + base_url） | DeepSeek/Kimi/通义/智谱全部兼容，换厂商只改一行配置 |
| Agent 架构 | 自写 agentic loop（30 行 while 循环） | 不用 LangChain，先理解原理 |
| 知识组织 | skill 机制（按需加载规程文件） | 避免把所有规则塞进 system prompt |
| 审查领域知识 | 存在工具函数 + skill 文件里 | 领域知识 = 评估集 + 工具 + 提示词 |
| 部署方式 | 纯客户端（无服务器） | 用户填自己的 key，最省事 |
| 打包 | Capacitor 打包网页为 APK | 复用现有 web 前端 |

## 五、开发历程（按时间）

### 第 1 阶段：学习路线规划
- 制定 8 周学习路线（API → tool calling → 打磨 → 实战）
- 关键认知：**Agent = 一个 while 循环 + 工具集 + 上下文管理**

### 第 2 阶段：Python 版 agent（DeepSeek）
- 用 OpenAI 兼容格式 + DeepSeek 搭建完整 agent
- 实现 tool calling 循环、工具、评估集

### 第 3 阶段：关键 Bug 修复（3 个经典问题）
1. **10 轮超限**：system prompt 强制调工具 + 工具 schema 为空 → 模型反复调工具。修复：提示词改为按需调工具、修正 schema、max_turns 10→20
2. **`Object of type function is not JSON serializable`**：把 Python 函数直接塞进 tools 参数。修复：说明书(schema)与实现(函数)分开传
3. **JSON 被 max_tokens 截断**：审查报告太长被掐断。修复：max_tokens 8192 + 输出自修复机制

### 第 4 阶段：普适化改造
- 从"单一合同"升级为"多类型普适审查"：识别类型 → 加载对应规程 → 审查
- 建 `skills/` 目录，7 份规程按需加载

### 第 5 阶段：输入校验
- 拦截无关输入（闲聊/借条/买卖等），提示重新输入，不浪费 token

### 第 6 阶段：纯客户端改造（JS 版）
- 把 Python 逻辑移植为 JS（config/tools/validator/agent）
- 支持浏览器直接调 DeepSeek API

### 第 7 阶段：打包 APK

- 网络坑记录：dl.google.com 被墙 → 腾讯云镜像；Gradle 超时 → 腾讯云 Gradle 镜像 + 阿里云 Maven 镜像

## 六、踩过的坑（经验值）

### 网络相关
1. **GitHub 推送失败**：误配了无效代理 `127.0.0.1:7897` → 清掉 git 代理配置，让 VPN（SakuraCat TUN 模式）接管即可
2. **dl.google.com 无法下载**：你的网络被墙 → 用腾讯云镜像 `mirrors.cloud.tencent.com/AndroidSDK/`
3. **Gradle 依赖下载超时**：`services.gradle.org` 大文件不稳定 → 腾讯云 Gradle 镜像 + 阿里云 Maven 镜像
4. **终端输出乱码**：Windows GBK 编码问题，不是数据错误；用 `PYTHONIOENCODING=utf-8` 解决

### 代码相关
5. `pass` 是 Python 保留字 → pydantic 用 `pass_` + `alias="pass"`
6. 函数与 schema 必须分离（给模型的 JSON 说明书 ≠ 给代码的 Python 函数）
7. 工具描述要写**触发条件**（"当用户问天气时使用"），不是只写功能

## 八、怎么继续开发

**改 web 前端**（index.html / config.js / agent.js 等）：
```
1. 编辑 webapp/ 下的文件
2. cp webapp/*.js webapp/*.html rental-app/www/   # 同步到安卓工程
3. cd rental-app && npx cap sync android          # 同步资源
4. 构建：cd android && ./gradlew.bat assembleDebug
5. 复制产物为 ZTC.apk
```

**提交到 GitHub**：
```
git add -A && git commit -m "描述" && git push
```
