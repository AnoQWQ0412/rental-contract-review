📋 租赁合同审查 ZTC

版本 1.0.0 · 设计者：Ano

一、软件说明

本软件是一款用于租赁合同风险审查的辅助工具，支持住宅、商铺、办公、设备、车辆等各类租赁合同。软件根据你粘贴的合同文本，自动识别类型并出具风险报告，供专业复核参考。

二、使用规范

  • 请使用真实、完整的合同文本进行审查；
  • 审查结果由 AI 模型生成，仅供参考，不构成法律意见；
  • 涉及重大权益的合同，请务必交由专业法律人士复核；
  • 请勿利用本软件进行任何违法活动或用途。

三、隐私与数据

  • 本软件为纯客户端运行，你的合同文本与 API Key 仅保存在你的设备本地；
  • 软件调用你自行配置的 AI 服务商接口完成审查，请留意所选服务商的隐私政策；
  • 请勿在合同中输入涉及个人敏感信息的非必要内容。
